# 🎯 遊戲列表

這裡收錄所有有 CBT 資訊的遊戲。

> 還沒有任何遊戲被收錄。點右上角 ✏️ 編輯按鈕來新增第一個遊戲頁面！

## 如何新增一個遊戲頁面

1. 在 `docs/games/` 目錄下建立新的 `.md` 文件（例如 `my-game.md`）
2. 參考下面的模板填寫資訊
3. 在本頁面加入連結
