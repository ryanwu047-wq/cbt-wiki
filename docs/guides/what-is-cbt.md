# 什麼是 CBT？

**CBT = Closed Beta Test（封閉測試 / 封測）**

是遊戲正式上市前，開發商邀請有限數量玩家進行的測試。

## 常見測試類型

| 縮寫 | 全名 | 說明 |
|------|------|------|
| **Alpha** | 內部測試 | 只有開發商內部員工可玩，通常不開放外部 |
| **CBT** | 封閉測試 | 需申請/抽選獲得資格，通常**刪檔** |
| **OBT** | 開放測試 | 所有人都能玩，通常**不刪檔**或接近正式上線 |
| **Pre-download** | 預先下載 | 正式開服前開放下載用戶端 |
| **RTM / Launch** | 正式上線 | 遊戲正式營運 |

## CBT 的重點

- **通常刪檔**：測試結束後角色資料會清除
- **需要資格**：透過官網申請、抽選、或搶號獲得
- **可能有 NDA**：部分遊戲要求簽署保密協議，不能直播/截圖
- **伺服器不穩**：測試期間常有維修、bug、連線問題
