# 如何申請測試資格

## 常見申請方式

### 1. 官網抽選
最常見的方式：到遊戲官網填寫問卷，開發商隨機抽出得選者。

- 注意填寫的 Email 要正確，錄取通知通常寄到 Email
- 部分遊戲會要求填寫遊戲經歷、設備規格

### 2. 搶號/先行體驗
開放固定名額，先搶先贏。

- 需要準時守在官網
- 建議提前註冊好平台帳號

### 3. 平台會員福利
- **Steam**：部分遊戲在 Steam 開放測試碼申請
- **Epic Games**：有時會給免費測試資格
- **官方 Launcher**：如 Riot、NetEase、HoYoverse 等平台會員有優先資格

### 4. 實體活動 / 內容創作者
- 參加展覽（如 Tokyo Game Show、Gamescom）現場領取
- 追隨官方 Discord / X (Twitter)，有時會釋出給粉絲

## 申請技巧

1. **多平台註冊**：同一遊戲可能在多個平台釋出資格
2. **準時**：開放申請當下就去填，不要拖到最後一天
3. **檢查垃圾郵件**：錄取通知有時被歸類為垃圾信
4. **綁好手機/驗證**：部分遊戲需要手機驗證才能取得資格
