# 關於本站

**CBT Wiki** 是一個開放整理的遊戲封測資訊站。

## 目的

很多遊戲在 CBT 期間資訊零散在各個論壇、Discord、PTT，這個 wiki 把它集中整理，讓想搶測試資格的人不用到處爬文。

## 誰可以編輯？

任何人都可以。每個頁面右上角有 ✏️ 編輯按鈕，登入 GitHub 即可修改。

## 技術

- 內容：[Markdown](https://www.markdownguide.org/)
- 靜態站生成器：[MkDocs](https://www.mkdocs.org/) + [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/)
- 託管：Cloudflare Pages
- 內容存放：GitHub

## 聯絡

有問題或想新增遊戲頁面？直接在站面上編輯，或開 GitHub Issue。
